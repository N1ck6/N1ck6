### Projects

| Project | What it is |
| :-- | :-- |
| [**Zapisal**](https://github.com/N1ck6/Zapisal) | Windows app + browser extension for online classes. Transcribes the lecture live (local Whisper on GPU or cloud), alerts you when your name or a roll call comes up, captures each new slide and builds structured notes (PDF, Obsidian-ready Markdown) when the class ends. Shipped solo as a product: installer with signed auto-updates, landing page, 3-week trial and a Telegram bot for licenses and payments.<br><sub>Python · FastAPI · faster-whisper · Chrome MV3 · Cloudflare Workers + D1</sub> |

Speaks in Jarvis’s voice, controls apps and media, browses the web through its own extension, types dictation anywhere and loads skills as plugins.<br><sub>Python · PySide6 · FastAPI · Ollama (Qwen3) · Vosk · GigaAM · Piper</sub> |

Auto generated registry entries. Release pipeline on GitHub Actions: unit tests, PyInstaller build, smoke tests of the packaged exe on real files, Inno Setup installer.<br><sub>Python · Windows Registry · FFmpeg · pytest · PyInstaller · Inno Setup · GitHub Actions</sub> |
| [**BOCSER**](https://github.com/N1ck6/BOCSER) | Research project in computational chemistry: Bayesian optimization over torsion angles with a physics-informed Gaussian-process kernel, which searches for low-energy conformers and transition-state conformers of flexible molecules. It runs ORCA quantum-chemistry jobs on a Slurm cluster, and a learned feasibility model filters out geometrically impossible candidates. I am the main contributor to this fork.<br><sub>Python · GPflow / Trieste · RDKit · ORCA · Slurm</sub> |
